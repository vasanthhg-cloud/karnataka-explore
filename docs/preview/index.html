This part needs the running app

The wishlist, review submission and saving an itinerary need a Python server and a database, so they are switched off in this static preview.

Sign-in, booking, the demo payment step, tickets and the admin console do work here — they run in your browser in demo mode. Everything else (all 31 districts, 116 destinations with galleries and maps, homestays, guides, dark mode) is fully browsable.
